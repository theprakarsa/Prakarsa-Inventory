# 📝 Riwayat Perubahan (Changelog)

## [1.1.0] - 31 Oktober 2026
### Added (Ditambahkan)
- Sistem UI baru: Tema Putih Bersih, Sidebar & Header Responsif.
- Fitur Import data (CSV) untuk 236+ aset legacy.
- Field baru pada database: `legacyCode`, `ownership`, `specs`, `depreciation`, `auctionStatus`, `quantity`.
- Fitur Print Label QR 5x4 cm.
- Fitur Print Laporan (CSS @media print).
- Dokumentasi (PRD, Database, API).

### Changed (Diubah)
- Mengganti format kode aset menjadi `PRAKARSA-UMM-[CAT]-001`.
- Background halaman menjadi abu-abu terang, form login dirombak.

## [1.0.0] - 30 Oktober 2026
### Added (Ditambahkan)
- Rilis awal (MVP).
- Auth JWT (Login/Logout).
- CRUD Master Data (Divisi, Kategori, Karyawan, Lokasi).
- Modul Peminjaman, Kerusakan, Pembelian, Instalasi.
- Manajemen User & Activity Log.
